# 📈 Success Metrics and Targets

Targets are starting placeholders, sized for a 13-week semester.

| Measure | Target | How tracked |
|---------|--------|-------------|
| Reach | 40+ unique attendees; 50% first-timers | Sign-in sheets |
| Progress | 25 members complete at least 3 foundation labs | Lab checkpoint log |
| Hands-on learning | Labs and challenges completed, not just attendance | Lab platform records |
| Cross-track work | 1 joint project with Web; 5+ members involved | Project repo |
| Practitioner badges | 5 members earn Practitioner | CTF and investigation scores |
| Mentorship | 3 members shortlisted as semester-two mentors | Mentor shortlist |
| Career readiness | 10 members with a GitHub write-up or CV update | Portfolio checkpoint |
| Feedback | 4/5 or higher from at least 70% of respondents | End-of-semester survey |

## End-of-semester deliverables
- A documented learning pathway for future cohorts
- A set of beginner and intermediate labs and challenges
- One completed Cyber × Web project with GitHub documentation
- A final showcase and demo session
- A semester impact report covering participation, completion, projects, feedback and recommendations
- A shortlist of students ready to mentor in semester two
