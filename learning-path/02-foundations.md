# Stage 2: Foundations

**Badge:** Learner · **Who it serves:** Beginners · **When:** Weeks 5–8

**Goal:** Learn the technical basics that everything else builds on.

> [!IMPORTANT]
> Practise only on systems built for it. See the [rules of engagement](../ETHICS-AND-RULES.md).

## What you will learn
- Networking basics: IP and MAC addresses, DNS and DHCP, TCP and UDP, ports, HTTP and HTTPS
- Linux and the terminal: files, permissions, SSH
- Web fundamentals: how sites, APIs and databases fit together

## Sessions and labs
- [Behind the Wi-Fi](../sessions/behind-the-wi-fi.md)
- [Networking lab](../labs/networking-lab.md)
- [Linux lab](../labs/linux-lab.md)
- [Web fundamentals lab](../labs/web-fundamentals-lab.md)
- Cyber Clinics (open question sessions)

## Hands-on
1. Complete the three foundation labs and log your checkpoints.
2. Bring your questions to a [Cyber Clinic](../engagement/README.md).
3. Start your GitHub write-up trail with the [write-up template](../projects/writeup-template.md).

## ✅ Checkpoint
- Can I explain what happens between typing a web address and seeing the page?
- Can I move around a Linux terminal and read permissions?
- Can I describe how a website, an API and a database connect?

If you can answer these, move to the next stage. If not, revisit the topics or ask in the channel.
