# Stage 4: Build

**Badge:** Builder · **Who it serves:** Practitioners (semester two focus) · **When:** Weeks 7–12

**Goal:** Contribute to a real, security-focused project.

> [!IMPORTANT]
> Practise only on systems built for it. See the [rules of engagement](../ETHICS-AND-RULES.md).

## What you will learn
- Security requirements
- Secure coding checks
- Testing
- Documentation on GitHub
- Demo

## Sessions and labs
- [Cyber × Web project](../projects/cyber-x-web/README.md)
- [Build It. Break It. Secure It.](../sessions/build-it-break-it-secure-it.md)
- [Secure project checklist](../resources/secure-project-checklist.md)

## Hands-on
1. Join a mixed-skill squad on the Cyber × Web project.
2. Write security requirements, test your own project and harden it.
3. Document it on GitHub and demo it at the showcase.

## ✅ Checkpoint
- Can I list the security requirements of a small web app?
- Can I show test evidence and the fixes I made?
- Is my documentation clear enough for a newcomer?

If you can answer these, move to the next stage. If not, revisit the topics or ask in the channel.
