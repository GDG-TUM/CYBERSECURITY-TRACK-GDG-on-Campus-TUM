## How to use this path
1. Start at the stage that fits you. Non-tech students begin with **Discover**, and nobody is thrown into advanced tools.
2. Finish each stage's **checkpoint** before moving on.
3. Stuck for more than 30 minutes? Ask in the channel or a Cyber Clinic.
4. Write up what you learn and add it to the repo.

> [!IMPORTANT]
> Every hands-on task assumes you follow the [rules of engagement](../ETHICS-AND-RULES.md).
