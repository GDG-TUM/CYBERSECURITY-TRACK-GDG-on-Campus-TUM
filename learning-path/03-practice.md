# Stage 3: Practice

**Badge:** Practitioner · **Who it serves:** Learners ready for hands-on work · **When:** Weeks 9–10

**Goal:** Apply your skills to guided investigations and a beginner CTF.

> [!IMPORTANT]
> Practise only on systems built for it. See the [rules of engagement](../ETHICS-AND-RULES.md).

## What you will learn
- Wireshark basics
- Log analysis
- Phishing investigation
- A beginner web security lab
- A beginner capture-the-flag (CTF)

## Sessions and labs
- [CSI: Cyber — Investigate the Incident](../sessions/csi-cyber-investigate-the-incident.md)
- [Wireshark and log investigation](../labs/wireshark-and-log-investigation.md)
- [Beginner web security lab](../labs/beginner-web-security-lab.md)
- [Beginner CTF](../labs/beginner-ctf.md)

## Hands-on
1. Complete a guided investigation and write down your timeline.
2. Take part in the beginner CTF as part of a team.
3. Publish a write-up of one lab or challenge.

## ✅ Checkpoint
- Can I read a packet capture or a log and explain what happened?
- Can I describe a web vulnerability in plain language and how to fix it?
- Did I follow the rules of engagement during the CTF?

If you can answer these, move to the next stage. If not, revisit the topics or ask in the channel.
