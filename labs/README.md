# 🧪 Labs

Hands-on labs turn concepts into skills. Progress is **measured by labs completed rather than attendance**, tracked in the lab checkpoint log and lab platform records.

## Tiers
Every lab has tiered tasks: a core path for beginners and stretch challenges for members with more experience.

## No lab access or slow internet?
Use local virtual machines and the free tiers of TryHackMe or Hack The Box, and offline-capable labs. Tell the Labs/CTF Coordinator if you are stuck.
