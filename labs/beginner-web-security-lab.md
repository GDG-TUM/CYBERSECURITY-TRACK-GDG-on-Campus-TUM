# Beginner Web Security Lab

**Stage:** Practice (Practitioner) · **When:** Weeks 9–10 · **Time:** 90 minutes

**Goal:** See common web weaknesses in a lab built for practice, and learn how they are fixed.

> [!IMPORTANT]
> Practise only on systems built for it. See the [rules of engagement](../ETHICS-AND-RULES.md).

## What you need
A free account on a practice platform such as PortSwigger Web Security Academy or TryHackMe.

## What you will be able to do
- Explain injection, broken access control and cross-site scripting in plain language
- Complete a guided beginner lab
- Describe how the weakness is fixed
- Write up the lab in your own words

## Steps
1. Create a free account on a practice platform (see [free resources](../resources/free-resources.md)).
2. Read the short explanation for the chosen topic.
3. Complete one or two guided beginner labs.
4. Use the [write-up template](../projects/writeup-template.md): what you tried, what worked, and how it would be fixed.

## ✅ Lab checkpoints
Log these with the Labs/CTF Coordinator. Labs completed, not attendance, count towards your badge.
- [ ] One guided lab completed
- [ ] Plain-language explanation of the weakness
- [ ] Fix described
- [ ] Write-up drafted

## Safety
Practise **only inside the lab environments** built for it. Never try these techniques on real websites.
