# 🚀 Getting Started

Do this checklist once, ideally before your first session. It takes about 45 minutes. **No technical background is needed** for the first stage.

## 1. Read the rules
- [ ] Read the [rules of engagement](ETHICS-AND-RULES.md)
- [ ] Post "I have read and agree" in the track channel

## 2. Secure your own life first (your Explorer starter pack)
- [ ] Strong, unique password on your email, plus two-factor authentication
- [ ] Two-factor authentication on GitHub and your main social accounts
- [ ] Screen lock and automatic updates on your phone and laptop
- [ ] Worked through the [account and phone safety checklist](resources/account-and-phone-safety-checklist.md)

## 3. Accounts
- [ ] **GitHub account** with [two-factor authentication](https://docs.github.com/authentication/securing-your-account-with-two-factor-authentication-2fa)
- [ ] Accepted your invitation to the **GDG-TUM** organization
- [ ] A **password manager** for your own accounts
- [ ] Free accounts on [TryHackMe](https://tryhackme.com) and, later, Hack The Box (check what is free)

## 4. Tools for the Foundations stage
| Tool | Why | Needed from |
|------|-----|-------------|
| **A Linux terminal** (Linux, WSL on Windows, or a virtual machine) | Linux lab | Foundations |
| **A virtual machine app** (for example VirtualBox) | Safe local lab machines | Foundations |
| **Git** and a **code editor** (VS Code) | Write-ups and the Cyber × Web project | Foundations |
| **Wireshark** | Packet and log investigation | Practice (week 9) |
| **A modern browser** | Most labs run in the browser | All stages |

You do **not** need an expensive laptop. If your setup struggles, tell the Track Lead. Offline-capable labs and local VMs are part of the plan.

> [!WARNING]
> **Keep your lab separate from your daily system.** Do not connect lab VMs to networks you do not own, and do not store personal data in them.

## 5. Configure Git
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## 6. Join the community
- [ ] Join the track channel
- [ ] Open a **Member Roadmap** issue in [member-roadmaps](https://github.com/GDG-TUM/member-roadmaps)
- [ ] Make your first contribution: [add your profile](members/README.md)

## 7. Know the community rules
- [Code of Conduct](https://github.com/GDG-TUM/.github/blob/main/CODE_OF_CONDUCT.md)
- [Contributing guide](https://github.com/GDG-TUM/.github/blob/main/CONTRIBUTING.md)
- [Security policy](https://github.com/GDG-TUM/.github/blob/main/SECURITY.md)
- Never commit passwords, API keys, tokens or `.env` files.
