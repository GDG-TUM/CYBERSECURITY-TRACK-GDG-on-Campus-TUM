# 🌐 Cyber × Web Project

## The idea
A **secure web platform** built with the Web track, covering HTTP, authentication, secure coding and vulnerability testing. It is the semester's Build stage: members work in **mixed-skill squads** so beginners learn from practitioners.

## What the project covers
- **HTTP and web basics:** how requests, sessions and cookies work
- **Authentication:** secure login, password storage and multi-factor options
- **Secure coding checks:** input validation, secrets handling, dependency checks
- **Vulnerability testing:** testing **your own** project and fixing what you find
- **Documentation on GitHub:** README, security notes and a test report
- **Demo**

## Squads
Each squad mixes skill levels and, where possible, Web and Cyber members. Suggested roles: builder, tester, reviewer and documenter, rotated.

## Rules
- Test **only your own project**. See the [rules of engagement](../../ETHICS-AND-RULES.md).
- Use the [secure project checklist](../../resources/secure-project-checklist.md).
- Never commit secrets.

## If the Web track is unavailable
The Cyber track runs the project internally as a [Build It. Break It. Secure It.](../../sessions/build-it-break-it-secure-it.md) squad.
