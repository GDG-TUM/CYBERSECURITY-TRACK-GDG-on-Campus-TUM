## Portfolio checkpoints
Write-ups and documentation are built into the learning process. The target is **10 members with a GitHub write-up or CV update** by the end of the semester.

## How to submit a write-up
1. Copy the template into `projects/writeups/<your-username>-<short-title>.md`
2. Fill it in with your own words
3. Open a pull request, or use the **Write-up submission** issue form
4. A maintainer reviews it and adds it to the showcase
