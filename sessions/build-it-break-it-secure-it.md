# Build It. Break It. Secure It.

**Format:** Teams build a simple app, test it, then harden it

**Stage:** Build (Builder) · **When:** Feeds the Cyber × Web project (weeks 7–12) (exact week and day **[TO CONFIRM]**)

**Goal:** Experience the full loop of building, testing and hardening, which is the heart of the Cyber × Web project.

> [!IMPORTANT]
> Practise only on systems built for it. See the [rules of engagement](../ETHICS-AND-RULES.md).

## What you will be able to do
- Write simple security requirements for an app
- Test **your own app** for common problems
- Fix issues and show before and after
- Document what you changed and why

## How it runs
1. Build: a small app with a login (30 min)
2. Break: structured testing of your own team's app (25 min)
3. Secure: fix and re-test (25 min)
4. Share lessons (10 min)

## Safety and set-up notes
**Test only the app your team built.** Use the [secure project checklist](../resources/secure-project-checklist.md).

## 🎯 Take-home Cyber Mission
Move your fixes into the project repo and write a short test report.
