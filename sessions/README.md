# 🎓 Session Bank

Question-driven titles keep sessions memorable. These eight are prioritised for **semester one**. The rest move to the semester-two bank.

| Session | Format | Stage |
|---------|--------|-------|
| [Would You Survive a Phishing Attack?](would-you-survive-a-phishing-attack.md) | Interactive phishing detective challenge using realistic messages | Discover (Explorer) |
| [Your Phone Is a Crime Scene](your-phone-is-a-crime-scene.md) | Mobile privacy, permissions and what a device reveals | Discover (Explorer) |
| [The Password You Think Is Strong… Isn't](the-password-you-think-is-strong-isnt.md) | Password attacks, MFA and account takeover demonstrated safely | Discover (Explorer) |
| [Behind the Wi-Fi](behind-the-wi-fi.md) | What happens after you connect: packets, DNS, IPs | Foundations (Learner) |
| [CSI: Cyber — Investigate the Incident](csi-cyber-investigate-the-incident.md) | Teams use logs and clues to reconstruct a fictional breach | Practice (Practitioner) |
| [Cybersecurity on Your CV](cybersecurity-on-your-cv.md) | Career paths, portfolios, GitHub, certifications, internships | Discover (Explorer) |
| [Build It. Break It. Secure It.](build-it-break-it-secure-it.md) | Teams build a simple app, test it, then harden it | Build (Builder) |
| [Cyber Escape Room](cyber-escape-room.md) | Security-themed puzzles as the showcase-week activity | Showcase |
