# 🆓 Free Resources

Always check each platform's current terms, free-tier limits and rules.

## Hands-on practice (legal labs)
- [TryHackMe](https://tryhackme.com): guided beginner labs
- [Hack The Box](https://www.hackthebox.com) and [Hack The Box Academy](https://academy.hackthebox.com): structured modules (check what is free)
- [PortSwigger Web Security Academy](https://portswigger.net/web-security): free web security training and labs
- [picoCTF](https://picoctf.org): beginner capture-the-flag challenges
- [OverTheWire wargames](https://overthewire.org/wargames/): learn Linux and security through games

## Guides and references
- [OWASP Top 10](https://owasp.org/www-project-top-ten/)
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org)
- [MITRE ATT&CK](https://attack.mitre.org)

## Tools
- [Wireshark](https://www.wireshark.org): packet analysis (free)

## Personal security
- [Have I Been Pwned](https://haveibeenpwned.com): check whether your email appears in known breaches

## Linux
- [The Linux Command Line (free book)](https://linuxcommand.org/tlcl.php)

## Git and GitHub
- [GitHub Skills](https://github.com/SKILLS)
