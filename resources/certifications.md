# 🎓 Certifications

Certificates help, but skills and write-ups matter more. Build first, certify second. Always check the official site for current exam details, requirements and prices.

| Level | Certification | Good for |
|-------|---------------|----------|
| Beginner | **ISC2 Certified in Cybersecurity (CC)** | Core security concepts |
| Beginner | **Google Cybersecurity Certificate** (online course) | Entry-level SOC skills and tools |
| Beginner | **CompTIA Security+** | Widely recognised foundation for security roles |
| Hands-on | **eJPT** (INE) | Practical entry-level penetration testing |
| Cloud | **Google Cloud Digital Leader / Associate Cloud Engineer** | Cloud basics, a good partner to security |

## How to prepare
1. Follow the learning path and write up what you learn
2. Use official study guides and practice labs
3. Study with a group from the track channel

See also the [Cybersecurity on Your CV](../sessions/cybersecurity-on-your-cv.md) session.
