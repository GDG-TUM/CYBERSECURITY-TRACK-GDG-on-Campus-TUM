# 📖 Glossary

| Term | Meaning |
|------|---------|
| **CIA triad** | Confidentiality, Integrity, Availability: the three basic goals of security |
| **Threat** | Something that could cause harm |
| **Vulnerability** | A weakness that could be exploited |
| **Exploit** | A way of taking advantage of a vulnerability |
| **Risk** | The chance and impact of something going wrong |
| **Phishing** | A fake message that tricks you into giving up information or clicking something harmful |
| **Social engineering** | Manipulating people rather than systems |
| **Malware** | Software designed to cause harm |
| **Two-factor / multi-factor authentication (2FA / MFA)** | An extra proof of identity besides your password |
| **Account takeover** | When someone else gains control of your account |
| **Password manager** | An app that stores unique passwords safely |
| **Hash** | A fixed-size fingerprint of data that cannot be turned back into the original |
| **Encryption** | Scrambling data so only someone with the key can read it |
| **TLS / HTTPS** | The technology that encrypts web traffic |
| **IP address** | Where a device is on a network |
| **MAC address** | A hardware identifier for a network interface |
| **DNS** | Turns names like example.com into IP addresses |
| **DHCP** | Hands out IP addresses to devices when they join a network |
| **TCP / UDP** | Two ways of sending data: reliable and ordered, or fast and light |
| **Port** | A numbered door on a device for network traffic |
| **Packet** | A small chunk of data sent across a network |
| **Firewall** | Controls which network traffic is allowed |
| **SSH** | A secure way to log in to another computer through the terminal |
| **API** | A way for programs to talk to each other |
| **OWASP** | A community that publishes web security guidance, including the Top 10 |
| **Injection** | Tricking an app into running attacker-supplied input as commands |
| **XSS** | Cross-site scripting: getting a website to run unwanted script in someone's browser |
| **Least privilege** | Give only the access that is needed and no more |
| **Patch** | An update that fixes a vulnerability |
| **Log** | A record of events on a system |
| **SOC** | Security Operations Centre: a team that monitors and responds to threats |
| **Incident response** | The process of handling a security incident |
| **Red team / Blue team** | Attackers (authorised) and defenders in security exercises |
| **CTF** | Capture the flag: a security competition with legal challenges |
| **MITRE ATT&CK** | A catalogue of attacker techniques |
| **Responsible disclosure** | Privately telling the owner about a weakness and giving them time to fix it |
